# Project Black - Social Distribution

Created as a part of CMPUT 404 - Web Applications and Architecture at the University of Alberta! [View the demo video here!](https://drive.google.com/file/d/1QSsr8EVWonZy5vkrim9iC4sdo1W_WdE9/view?usp=sharing)

## What is Social Distribution?

Social Distribution is a Django-based social networking application built around federation: separately deployed instances that can exchange content so people can interact across these 'nodes' (that is, all the other projects built in the class by other teams.)  It functions like a standard social media platform - users can create accounts, share posts and images,  like content, interact with each other, and control who can see their posts.

## My Role

I was officially a backend developer starting off, but my work grew into implementing complete features across the application. I built the likes, image upload, and post visibility features, working on both the Django backend and the frontend interactions needed to make them usable. I also took part in debugging wiring issues and writing up test code. Later, I helped investigate federation issues between independently deployed nodes and coordinate this with other teams. I traced how data moved through our APIs, tested requests and responses, and worked through integration problems so the nodes could exchange content as expected.
